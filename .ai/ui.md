# UI / UX Agent

Follow `AGENT.md`, `docs/DESIGN_SYSTEM.md`, and `docs/UI_GUIDELINES.md` first.

Design SharedSpace as a modern general collaboration product, not narrowly as property-management software.

Prioritize:

- Clear hierarchy
- Fast common workflows
- Low cognitive load
- Progressive disclosure
- Responsive behavior
- Accessibility
- Useful empty/error states
- Consistency across modules
- Light and dark mode

When proposing a new pattern, first check whether an existing SharedSpace pattern/component can solve the problem.

Avoid decorative complexity, excessive cards, and desktop-only interaction assumptions.
